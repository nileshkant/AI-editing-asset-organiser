## Schema, bounds and recovery

See [IMAGE_IMPORT.md](../IMAGE_IMPORT.md) for the full state machine and named
limits. v11 is additive and transactional with a consistent pre-upgrade backup.
Genuine populated v10 migration preserves image annotations; a deliberate table
collision midway through v11 creation rolls back all new tables and user_version.
Existing genuine v5/v7/v9 migrations and audio preservation fixtures still pass.
Restore validates typed metadata/counters/budgets before mutating live or rollback
files, refuses active imports, and cancels restored active work. Backup/restore,
invalid counter rejection, exact membership, live/cancelled leases and expired
owner recovery have dedicated job tests. Actual 100K-row fixtures exercise the
item cap, bounded terminal eviction and idempotent rediscovery at the exact cap.

There are 32 active / 1000 retained jobs, 100K retained items and 128 MiB logical
job metadata, not a claim about exact SQLite/RSS size. Paths/previews/pages/source
context/discovery are separately bounded. Originals are read-only. Deletion of a
job/source cascades its local history; history eviction never deletes asset
annotations. Shared technical warnings follow immutable content/analyzer keys.
Optional AI consent, models, editable binary artifacts, export and image MCP are
inapplicable here: this ticket adds none of those surfaces.

## Review findings resolved

- Directory containment initially reused the file-only resolver; the nested-folder
  integration test exposed it. Added a contained-directory resolver, retaining
  full sibling exclusion and symlink validation.
- Full-cap rediscovery initially reserved budget for existing rows; it could strand
  a recovered 100K-item job. Budget now reserves only genuinely new unique paths,
  with an actual 100K-row recovery regression test.
- Stale source generations could strand a running job after rejecting publication.
  The owner now terminates its stale job without accepting results or touching a
  new owner's lease; generation-change integration coverage verifies it.
- Native modal disabled its opener before capturing focus; real-browser checks
  caught focus loss missed by jsdom. Capture the opener before disabling it.
  Browser regression also exposed an old deferred inspector close callback that
  could steal a newer `/` search focus; it now respects newer focus actions.
- Genuine old-schema fixtures must remove the new cross-lane triggers as well as
  image tables. The v7 migration regression caught that fixture contamination;
  the shared genuine-schema helper now removes both before constructing old DBs.
- Existing folder catalogs and evicted cancelled histories must not re-enable
  audio-only metadata writes. A durable source binding keeps that guard alive;
  tests prove original sidecars remain untouched.
- Escaped long paths can exceed a nominal 50-row IPC budget. Item pagination now
  counts actual serialized bytes, reserves a worst-case escaped cursor and
  preserves every item across pages, covered by a dedicated long-path fixture.
- Source-stamp updates now reserve their budget before writing, including retry.
  Authoritative polling drops evicted history; a mutation epoch prevents an older
  in-flight read from hiding a newly confirmed/cancelled/retried job. The final
  focused image-core run passed 31 tests; renderer state/eviction tests passed.

- Scheduler recovery must revisit leases that expire after startup. A single
  startup recovery would leave such a crashed job stranded. Each scheduling tick
  now checks expiry; a real-worker regression starts the scheduler first, expires
  a simulated crashed owner later, and verifies rediscovery and ready publication.
