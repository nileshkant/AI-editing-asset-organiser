# SS-030 — CreativeShelf branding compatibility

Visible React UI, page/window/bundle names, catalog Markdown, MCP handshake
metadata and generated client label now use CreativeShelf. The stable installed
identifier, storage/log fallback paths, executable/environment aliases and
persisted schema versions are intentionally preserved. See
`docs/BRANDING_COMPATIBILITY.md` for upgrade and rollback policy.

Validation on 2026-10-02:
- `npm test`: 128 tests passed across 11 files, including visible UI expectations.
- `npm run build`: TypeScript and Vite passed.
- FFmpeg/ffprobe-configured `cargo test --workspace -- --include-ignored`:
  168 tests passed, zero failed/ignored. This includes old portable-catalog
  roundtrip, migration backups, exported manifests and legacy stdio bridge.
- Bundle configuration has CreativeShelf product/window names and unchanged
  `app.soundshelf.desktop` identity. Release override does not replace these.

A populated installed upgrade, signing, installer replacement and reconnect
checks remain SS-024/031 release gates. No media or user database was modified.
The name change itself changes no persisted schema or storage identity.
