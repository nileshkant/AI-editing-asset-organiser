## Acceptance evidence

- Catalog usable without rereading audio: roundtrip test maps an empty relocated folder, restores measured profiles, searches metadata and asserts no analysis jobs. Only legacy migration hashes audio.
- Schema versioned: portable v1/legacy v3 discriminators; unknown schemas rejected. SQLite v6 transactional upgrade from frozen v5 fixture, with metadata preservation, pre-upgrade backup and failure rollback.
- Configurable roots: native chooser mappings, offline unmapped imports and verified relink preserve sound/source identity.
- No credential/settings exports: typed snapshot includes catalog data only. Tests exclude absolute source roots, settings/credential/grant fields. User-authored names/comments/queries are intentionally retained and documented as user-controlled sharing content.
- Legacy descriptions: separate legacy_filename_inference evidence persists after native reanalysis.
- Old 20-second measurements: coverage explicitly labeled first_up_to_20_seconds_12khz_mono; original metrics never populate the native measured profile. Legacy pending sounds are analyzed with the existing worker.
- Annotations: Unicode tags/comments/favorites survive roundtrip and legacy reanalysis; current clips and saved searches also survive.

## Review findings and resolutions

- A source import could reach an identity or saved-search-name collision after earlier inserts. One transaction now protects all imported sources, sounds, profiles, annotations, clips, searches and evidence. Late saved-search collision test asserts exact unchanged export.
- Folder scanning would broaden a legacy import to uncataloged siblings. Legacy sources use explicit files membership; a 300-file test also verifies durable scanning does not hit the targeted-picker limit of 256 entries.
- Native commands must not accept arbitrary renderer-selected catalog paths or root paths. Files are picked/saved natively; root grants are bound to preview token/source ID, and confirm consumes the immutable preview and grants. Cancel/unmount revokes the preview. Expired previews reject mapping.
- Direct export writes could leave a partial final document. Exports now stage a unique sibling file and publish atomically with a no-replace hard link; cleanup touches only owned staging files.
- Shared content digests could contain conflicting measured profiles. Validation and cache-conflict checks reject these rather than overwriting shared analysis.
- Fresh initialization and historical migrations need distinct v6 handling. Frozen v5 fixture plus v3/v4 regression suites verify the new table is created once and older content is preserved.
- Queue failure after successful legacy metadata import must not appear to roll back data. The import report explicitly warns and offers Rescan recovery.

## Limits

Portable catalogs contain metadata and current recipes, not audio or historical recipe revision history. Legacy support intentionally accepts only the known v3 format. Root mapping does not hash portable audio; verified relink/rescan is the integrity workflow. Missing legacy media fails the whole import. Imports do not silently merge overlapping roots or existing identities. JSON is the restore format; Markdown is a readable companion. Windows/Linux installed UI, permissions and actual audio output remain unverified locally. Native CI runs real media fixtures on all three supported platform runners.
