# SS-028 review: Windows application icon resource

## Findings

- Tauri's Windows build script requires `src-tauri/icons/icon.ico`. The
  repository previously shipped only `icon.png`, which stopped the
  `windows-latest` GitHub Actions job before Rust tests ran.
- A multi-image Windows ICO generated from the existing SoundShelf brand PNG
  is committed at the Tauri default path.
- `scripts/icon-resource.test.js` fails if the ICO is missing, malformed, or
  reduced to a single embedded image.

## Verification

- `npm test` includes the icon resource check and reports more than one
  embedded ICO image.
- Pull request #1 (`fix/SS-028-windows-icon-resource`) merged into `main` as
  `975c522`, after which the Verify workflow runs `cargo test --workspace --locked`
  on `windows-latest`.
- Installer signing and platform-specific icon refinements remain in SS-024.

## Residual risk

Windows icon appearance in the signed installer and taskbar is not qualified
here. This ticket only unblocks compilation and CI.
