## Result

Added an additive, versioned image data contract with Rust serializers/validation
and TypeScript types/validation. The conformance bundle is explicitly not a new
portable-catalog format. No database migration, image commands, decoder, provider,
UI, or capability was enabled. No existing sound/clip type was changed.

The implementation lives in an isolated worktree based on current origin/main.
Unrelated source-catalog edits and the locally authored backlog in the original
workspace were not incorporated into this implementation branch.

## Review findings and corrections

- Required nullable fields initially risked Rust's implicit missing-as-null
  behavior; nullable deserialization now rejects omitted fields.
- Shared validation explicitly rejects lone Unicode surrogates and sparse
  JavaScript arrays rather than relying on JSON serialization to repair them.
- Integral JSON spelling differed between typed Rust deserialization and JS;
  the bundle parser now normalizes safe integral JSON floats before typing.
- A complete AI state without current model evidence could falsely imply
  completed analysis; validation and a shared regression case reject it.
- Existing audio identity/payloads and exact MCP discovery are frozen with
  synthetic fixtures rather than assumed compatible from compilation alone.
- Original workspace snapshot-size edits were excluded; the contract inventory
  truthfully records the merged baseline, not uncommitted behavior.
