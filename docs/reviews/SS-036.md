# SS-036 review

Replaced the long Settings page with five labelled ARIA tab/pane pairs. Roving
focus supports Left/Right, Home/End; native buttons support Tab/Enter/Space.
Hidden panes stay mounted so imports do not lose preview tokens and one-time
credentials/recovery results survive category changes. Original unmount cleanup
still releases pending previews when leaving Settings.

Styles are scoped to Settings. System fonts, native selects and checkboxes,
grouped cards, wrapping action rows, bounded fields, selectable wrapping code,
visible focus and forced-colors selected-tab borders are retained. Removed the
hardcoded Development label, using the actual app-info version.

Validation: 160 frontend tests pass (four new interaction regressions). Production
TypeScript/Vite build passed. Browser visual QA uses
the real Settings component with simulated IPC and disposable data, no live
application/catalog or real filesystem commands. At 720x560 all five panes had
clientWidth=scrollWidth=520 and document width 720; wide and compact screenshots
were inspected. Sources include long POSIX/Windows paths and a missing file;
running MCP shows the full permission form. The temporary harness is not shipped.

Review caught and corrected a fixture's wrong IPC command and unsupported
Testing Library typing. Existing source confirmation, backup and MCP tests stay
enabled. The 194 native workspace tests passed under SS-035 before this UI-only
branch; native platform CI runs independently for this branch.

Installed platform scaling, VoiceOver/Narrator/Orca and native webview appearance
are pending. Browser simulation does not qualify all desktop environments.
The testing-team protocol is in tickets/SS-036.md.
