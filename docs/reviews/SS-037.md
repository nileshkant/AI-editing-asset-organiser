# SS-037 review evidence

Persistent production constructor stores per-client hashes, scoped permissions,
enabled state and the actual bound port in a separate SQLite database. Catalog
exports/backups do not include it. Unix mode is 0600; Windows uses the user app
data directory's inherited permissions. No plaintext token is persisted or
returned by status. Existing ephemeral test constructors retain their contract.

Review fixes: Stop and Quit are distinct; explicit Stop saves disabled state
before closing access, while Quit keeps startup enabled. New listener sessions
receive new revocation flags so old sessions cannot regain access on restart.
Credential changes persist before changing live authorization; failed writes
preserve the existing token. Startup failure closes its owned listener and
removes discovery, without resetting pairings or choosing another port.
