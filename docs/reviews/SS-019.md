## Implementation and acceptance

- Read, edit, export and source-path grants are distinct. The desktop pairs explicit source IDs; default write/path permissions are off. The HTTP gate carries internal client identity into SDK context and checks token/revocation on every request. Discovery and direct calls both enforce grants.
- Core `AgentLibrary` calls the existing search, annotation, clip, portable-catalog and export services. Scoped SQL filters sources before decoding profiles; source membership filters occur before vocabulary, ranking, facets and totals. Empty scopes never fall through to all sources. Shared search now applies explicit source filters before typo vocabulary construction, preserving UI/MCP parity.
- Search uses indexed metadata with no rescan, hashing or decode. Content hashes and indexed availability are returned. ID/version and clip revision checks reject stale writes/exports; resolve and export enforce source containment and current availability.
- Search/clip/job pagination is bounded at 100, offset 1,000,000. Tool responses cap at 2 MiB. Portable catalog export preserves full measured profiles for selected sound IDs, includes only corresponding sources/clips/evidence and removes global saved searches. Root maps are null without explicit source-path permission.
- Native save dialogs approve an exact one-use destination for one client. Export tools cannot supply paths. Bounded worker/job/retry registries return a job promptly. Idempotent retries do not create duplicate clips/exports. Job access/cancellation is owner-restricted. Public failures and export indexing warnings are sanitized. Revocation/Stop cancels owned work/grants; full shutdown joins workers. Completed native publication wins cancellation races.

## Review fixes and limitations

Review fixed the initial portable subset's omitted waveform: shared search intentionally strips waveform data, so catalog export re-reads only its authorized selected IDs to preserve a valid portable profile. Shared search vocabulary now respects explicit source filters. Cancellation has its own flag so a request racing worker startup produces a cancelled job instead of a misleading invalid-grant failure. Pending grants are cancelled on revoke/Stop; indexing warnings expose no raw diagnostics.

No schema migration or source media mutation. Export job/retry snapshots are session-only; native committed output/journal recovery and import jobs remain durable. Offset pages may shift as the UI edits/imports; this is not a revision-frozen cursor. The exporter keeps its existing single pending native grant and single render limit. Physical save-dialog/menu interaction, installed-client configuration adapters, Windows symlink privilege tests, installer bridge packaging, and broad security/performance qualification are not claimed. Exact revision CI results are available in [PR #16 checks](https://github.com/nileshkant/AI-editing-asset-organiser/pull/16/checks), which run the full real-media workspace on macOS/Windows/Linux; installed platform qualification is still required.
