# SS-011 review: Waveform visualization

## Scope

Per-channel min/max/RMS multiresolution pyramid, versioned binary disk caching (`.sswf`) with on-demand rebuild, canvas 2D waveform workstation with stereo channel separation, deterministic zoom and pan, accessible numeric region selection, and native playback cursor tracking.

## Acceptance Criteria Verified

- **Peaks derive from decoded samples**: Decoded raw PCM stream from FFmpeg or PCM reader is analyzed per-frame to compute true minimum, maximum, and RMS buckets. No arbitrary or decorative mock bars.
- **Zoom/pan deterministic**: Deterministic viewport mapping between pixel coordinates, sample frame indices, and timestamps in seconds across zoom levels 1x (fit-to-window) to 64x with smooth horizontal pan bar.
- **Stereo separate**: Stereo audio renders discrete channel lanes (Left `L` and Right `R`), preserving anti-phase stereo extrema (+0.75 L, -0.75 R) without summing or destructive phase cancellation; toggleable to combined view.
- **Selection accessible numerically**: Interactive selection regions with draggable start/end boundary handles, plus exact numeric spinbutton inputs for Start (s), End (s), and Duration (s) with clamping and keyboard nudging (<kbd>←</kbd> / <kbd>→</kbd>, <kbd>i</kbd>, <kbd>o</kbd>).
- **Cursor matches source frames**: Playhead cursor tracks the native playback frame clock (`playback.position_seconds * sample_rate`). Clicking or dragging on the canvas seeks native playback directly at the exact frame/second position.
- **Caches versioned**: Binary cache format (`.sswf`) with 64-byte header containing magic bytes `SSWF`, format version 1, algorithm version 1, sample rate, channels, levels count, base bucket size, total frames, and a 32-byte Blake3 cryptographic checksum. If missing or corrupted, the system detects checksum mismatch and automatically rebuilds the cache from the source audio file.
- **No full-file PCM in renderer**: Frontend queries bounded viewport slices via `get_waveform` IPC command; payload is strictly capped (e.g. 1200 points), guaranteeing lightweight memory footprint and smooth 60fps rendering regardless of file length.
