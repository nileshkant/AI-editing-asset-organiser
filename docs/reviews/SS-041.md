## Review findings addressed

1. A whole-library portable guard must not break unrelated audio snapshots:
   added per-source audio export with its own consistent read transaction.
2. Checking for images only before snapshot staging left a registration race:
   recheck under an immediate DB write transaction at final publish and rebuild,
   in addition to the app mutex and OS folder lock.
3. SQLite integrity alone accepts semantically malformed JSON/lineage: restore
   audits typed records, registry coverage, membership and current history before
   live/rollback mutation. Lineage allows absent parents per SS-040, rejects known
   audio parents and cycles/depth >1000.
4. Multiple openers could each observe an old version: serialize migrations,
   reread schema and detect data changes during backup, never apply duplicate DDL.
5. Old tests synthesized old versions from the latest schema: their disposable
   fixtures now remove the empty image schema first, instead of weakening DDL
   collision detection. The frozen v9 audio wire fixture remains unchanged.
