## Requirement coverage

- **R1 allowlist and attribution.** Five formats (A1111 parameters, ComfyUI
  prompt graph, InvokeAI, NovelAI, IPTC digital source type) plus Software and
  EXIF date as supporting claims. Read from PNG text and compressed and
  international text chunks, PNG eXIf, JPEG APP1 EXIF and XMP, WebP EXIF and XMP,
  and authorized `<stem>.txt` sidecars. Each claim records format, container and
  key; each result records parser `creativeshelf-generation-v1`.
  - U: *a1111_parameters_map_every_documented_field_losslessly*,
    *comfyui_graph_is_read_as_data_and_workflows_are_never_run*,
    *invokeai_and_novelai_metadata_map_with_their_own_attribution*,
    *jpeg_and_webp_exif_user_comments_carry_a1111_parameters*,
    *xmp_digital_source_type_is_an_embedded_claim_without_xml_expansion*,
    *sidecars_need_the_a1111_layout_and_a_size_limit*.
  - I: *embedded_metadata_is_read_on_import_without_changing_readiness_or_bytes*.
- **R2 field mapping.** Prompt, negative prompt, generator, model, seed (text,
  so 20-digit seeds survive), sampler, settings, created time with its offset or
  "time zone unknown", and references (model hash, LoRA, image, other). A seed
  written as an inexact JSON number is left unknown with an issue.
  - U: *a1111_parameters_map_every_documented_field_losslessly*,
    *ambiguous_graphs_and_inexact_seeds_stay_unknown*,
    *unicode_prompts_survive_international_and_compressed_chunks*.
  - R: *shows every value with its source…* (time zone unknown, conflict note).
- **R3 unknown, empty, claim and confirmation.** `None` versus `Some("")`;
  redacted fields are listed. Imported claims and your record are stored
  separately, and a review is tied to the exact content hash, parser and sidecar
  revision. Workflows and unknown chunks are kept as name and byte count only.
  - U: *empty_and_absent_values_stay_distinct*,
    *unknown_generators_and_plain_metadata_are_not_claims*.
  - I: *user_provenance_is_revisioned_and_survives_file_and_claim_changes*.
  - R: *distinguishes unread, redacted and empty values*.
- **R4 nothing inferred, run, fetched or followed.** The reader takes bytes
  only and has no file system or network access. No pixel data is examined.
  Graph nodes are data; the ComfyUI `workflow` is never parsed. Sidecars are
  read only for folder sources and only inside the root. References that look
  like local paths are private.
  - U: *non_images_and_pixels_never_produce_claims*,
    *comfyui_graph_is_read_as_data_and_workflows_are_never_run*.
  - I: *sidecar_changes_are_versioned_and_exact_file_grants_never_read_siblings*.
  - R and E: prompt text containing markup renders as text, with no links or
    images.
- **R5 manual entry, origin, search policy and export opt-in.** Inspector section
  with per-field origins, a revision-checked editor, and review and withdraw
  actions. Catalog data settings carry the per-export prompt and private
  reference options, the search policy and the folder snapshot setting.
  - I: *user_provenance_is_revisioned_and_survives_file_and_claim_changes*
    (stale revision is `CONFLICT`), *shared_exports_redact_prompts_and_paths_unless_opted_in*
    (search text per policy).
  - R: *saves only changed fields…*, *reloads the latest provenance after a
    conflicting change*, *shows review state and stays read only…*,
    *keeps prompts out of exports unless chosen*, *saves search and folder
    snapshot settings*, *is hidden when image support is off*.
  - E: keyboard edit, review and settings flow; axe clean.
  - Image search itself is SS-058. The setting says so and nothing is indexed
    yet. `Catalog::image_generation_search_text` is the hand-off.
- **R6 limits and readiness.** Limits are listed in GENERATION_METADATA.md and
  enforced as `limit_exceeded` without truncation. Metadata failures never
  change technical state.
  - U: *compression_bombs_and_oversized_prompts_stop_without_truncation*,
    *segment_count_is_bounded*, *malformed_json_and_chunks_are_reported_and_isolated*,
    *parser_time_budget_stops_work*.
  - I: *metadata_reader_cost_is_bounded_on_large_and_hostile_files*,
    *embedded_metadata_is_read_on_import_without_changing_readiness_or_bytes*
    (malformed metadata still `ready`).
- **R7 changed versions and sidecars.** Results are keyed by content hash, so a
  new version gets its own and your record stays. Sidecar evidence has its own
  revision: changed contents or removal bump it, and an unchanged stat skips the
  read. Libraries upgraded from v15 are read once on the next check.
  - I: *user_provenance_is_revisioned_and_survives_file_and_claim_changes*,
    *sidecar_changes_are_versioned_and_exact_file_grants_never_read_siblings*,
    *upgraded_libraries_read_metadata_once_on_the_next_check*.
- **R8 portable, snapshots, derivatives and redaction.** Portable v2 image
  records carry an optional `generation` field; prompts and private references
  are removed unless opted in, and the removal is recorded. Folder snapshots
  follow the library setting, and changing it marks snapshots dirty. Restore and
  import validate records. Derived elements inherit per field through lineage.
  - U: *redaction_removes_prompts_and_private_references_and_records_it*.
  - I: *shared_exports_redact_prompts_and_paths_unless_opted_in*,
    *folder_snapshots_follow_the_library_sharing_setting*,
    *derived_elements_inherit_parent_provenance_per_field*,
    *restore_refuses_backups_with_invalid_generation_records*.

## Contract checks (T4, T5)

- **Authorization.** Sidecars follow the source scope; edits use the annotation
  editability check (original available, inside its scope).
- **Concurrency.** Edits are optimistic on `revision`; a stale write is
  `CONFLICT` and the UI reloads. Extraction storage uses both publish fences of
  the import, so a superseded job cannot write a result.
- **Cancellation.** The one-time read for upgraded libraries checks the job lease
  and verifies the hash before storing.
- **Persistence and recovery.** Every new column is classified in
  `persistence_inventory`; backup validation checks the three tables; schema
  v17 upgrade is transactional with a pre-upgrade backup (M tests).
- **Resources.** Limits above; measurements below.
- **Accessibility.** Labelled section and form, live status, keyboard flow and
  axe in E.
- **Legacy audio.** The full workspace suite passes (below); audio portable v1
  output is unchanged; image file hashes are unchanged after import (I).

## Performance (release build, this container)

`cargo test -p soundshelf-core --release --test image_generation metadata_reader_cost -- --nocapture`:

| Case | Result |
| --- | --- |
| 24.6 MB PNG, parameters after the image data | 9.96 µs per extract (walks chunk headers, never pixels) |
| First read of new content: streamed hash vs read + hash + extract, warm cache | 9.4 ms vs 16.3 ms per 24 MB file |
| Hostile PNG, 72 zlib bombs of 900 KiB | 3.5 ms (3.4–3.8 ms over earlier runs), status `limit_exceeded` |

Holding the bytes costs one extra buffer of the file size during import; the
existing image read cap bounds it. Images already read never pay this again.

- No C2PA manifests.
- Renderer tests are jsdom; the Playwright run uses the desktop IPC fixture, not
  the native shell.
- Tested on Linux x86_64 only locally; CI covers macOS and Windows.
