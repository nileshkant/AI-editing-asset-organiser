# SS-008: Offline natural language and fuzzy search review

## Overview

SS-008 delivers SoundShelf's complete offline search engine, combining structured natural-language parsing, lexical scoring with exact-match precedence, contiguous quoted phrase matching, prefix and natural-language exclusions, synonym expansion, typo correction with vocabulary constraints, Unicode/diacritics normalization, faceted aggregations, and saved searches persistence with transactional SQLite schema migration (v2 -> v3).

## Key Implementation Components

1. **Natural-Language Interpretation & Parsing (`crates/core/src/search.rs`)**:
   - Parses duration constraints ("under 3 seconds", "less than 10s", "over 1 minute").
   - Scans and extracts contiguous quoted phrases (`"laser blast"` / `'laser blast'`).
   - Handles negative filters both via prefix (`-vocals`, `-"heavy boom"`) and natural-language keywords (`without vocals`, `excluding thunder`).
   - Normalizes diacritics and accents (e.g. `flûte` -> `flute`, `éclat` -> `eclat`) and supports CJK ideographic queries without whitespace boundaries.

2. **Lexical Scoring & Deterministic Ranking**:
   - Exact full-title match bonus (+1000).
   - Exact user tag match bonus (+250).
   - Quoted phrase matches (+100 to +300).
   - Token relevance across title (+30), user tags (+20), profile tags (+10), comments (+4), and profile descriptions (+2).
   - Multi-tier deterministic tie-breaking: `score DESC`, `title.len() ASC`, `title (case-insensitive) ASC`, `id ASC`.

3. **Vocabulary-Constrained Typo Correction**:
   - Transposition (`scartch` -> `scratch`), single-character errors (`whooshh` -> `whoosh`), and omissions (`lasr` -> `laser`).
   - Distinct semantic words in the audio domain are preserved: real dictionary words like `train` and `rain` are guarded against cross-mutating into each other.
   - Typo vocabulary calculation is deferred lazily and skipped when all query terms are recognized audio keywords.

4. **Dynamic Search Facets**:
   - Returns top 30 user and profile tags with sound counts.
   - Aggregates audio channel layouts (`mono`, `stereo`, `5.1`, etc.).
   - Computes duration buckets (`under 3s`, `3s - 15s`, `over 15s`).

5. **Saved Searches & SQLite Migration v3 (`crates/core/src/schema.sql`, `catalog.rs`)**:
   - Schema version bumped to `3`.
   - Transactional migration in `Catalog::open` creates `saved_searches (id, name, query, created_at)` table.
   - Provides `Catalog::save_search`, `Catalog::saved_searches`, and `Catalog::delete_saved_search`.

6. **Shared Canonical Search (`Catalog::search`)**:
   - Both Tauri IPC (`search_sounds`, `save_search`, `saved_searches`, `delete_saved_search`) and future MCP services execute the identical `Catalog::search(&query)` API.
   - Zero hidden cloud calls: all searches and aggregations occur 100% locally.
   - Result payloads omit waveform peaks to keep IPC transfer fast and lightweight.
