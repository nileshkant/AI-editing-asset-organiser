# SS-008 initial search increment

Implemented: shared typed query, offline duration intent, vocabulary-constrained typo correction, synonym groups, exclusions, tags, favorites, source filters, deterministic ordering and bounded pagination. Results omit waveform payloads. AI is not used.

Validation: `node scripts/cargo.mjs test -p soundshelf-core --locked`: 24 tests passed, including 14 search tests. Tested whoosh/swoosh, transposed scratch, rain/train distinction, numeric boundaries, annotations, exclusions, pagination and hidden offline/missing assets.

Review: legitimate known words must not be fuzzy-corrected into another sound category. Required terms use AND semantics. Explicit numeric filters stay strict. Input length/result limits bound user-controlled work. First compile caught an iterator type mismatch; corrected before successful tests.

Remaining acceptance criteria: SQLite FTS-backed candidate retrieval, saved queries, facets, 100k benchmark, locale-aware search and broader natural-language evaluation. Current implementation is an in-memory first increment, not the final large-library search engine. UI/MCP integration will call this service. Self-review; PR pending remote.
