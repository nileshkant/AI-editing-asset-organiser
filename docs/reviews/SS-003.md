# SS-003 review

Scope: transactional SQLite schema, stable source/sound identity, content-addressed analysis, independent annotations and strict root relinking.

Tests: 10 catalog tests cover relink/reuse, changed content, wrong-root rollback, incomplete scans, offline sources, traversal, symlink escape (Unix), duplicate/overlapping roots, restart persistence/tag normalization and invalid measurements. Run with `node scripts/cargo.mjs test -p soundshelf-core --locked`.

Review decisions: a move hashes content for verification but does not decode or recompute profiles. Source generations reject stale workers. User metadata is separate from analysis. Relink currently requires all non-missing files to match; mixed/partial relocations intentionally fail without mutation and remain follow-up UI work.

Limitations: current read repository materializes sounds in memory; indexed paginated search is a later ticket. Filesystem I/O must run on workers, not the renderer/command event loop. Watcher-driven availability is not yet connected. No cross-platform runtime qualification. Self-review only; PR publication pending remote.
