checks unchanged. Its stage purpose is `unsigned-tester-prerelease`; macOS uses

frontend/native real-media tests, build verified minimal media, extract the actual

upload. Changed macOS executable resources must match after stripping only the
ad-hoc signature from both copies. Release publication waits for every platform.

provenance and corresponding FFmpeg source, with installation/security warnings
and remaining physical/client/accessibility/stability qualification stated openly.
This path implements the user's changed distribution scope; it does not complete
the signed production acceptance criteria. Local frontend 152 tests and production
frontend build passed. Native packaging and archive inspection results will be
recorded from the hosted release run; they are not claimed before it succeeds.
