# SS-024 review — native candidate tooling (partial release qualification)

Candidate preparation now supports macOS, Windows x64 and Linux x64. Verified
signed-source FFmpeg preparation replaces reliance on unreviewed developer tools.
Exact resource staging, architecture/runtime closure checks, platform signing,
installer inspection and package size reporting fail closed on missing evidence.
The installed MCP bridge is discoverable through Settings. Release startup requires
bundled media. No catalog schema changes or source recordings are shipped.

Evidence on macOS arm64, 2026-10-02:

  traversal rejection, exact staging, missing resources, signature byte changes,
  renamed SQLite/WAV exclusion and linked inputs. Three native closure fixtures
  reject custom Windows DLLs and dynamically linked Linux media.

  8c3850283eb25fa026482078a04051e0be17347b09ef81a0849bec15a96e002e.
  The actual minimal tools built and passed `release:check`. Combined executable
