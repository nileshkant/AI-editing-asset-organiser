# SS-024 review — packaging gates (partial)

The guarded candidate command now rejects missing reviewed media locks before
building. Resource staging includes only two audited media tools, the compiled
MCP bridge, a license notice and build provenance through explicit Tauri resource
maps. Binary hashes/sizes, bounded regular inputs, architecture, native version
and static LGPL configuration are checked. macOS preflight rejects non-system
library dependencies. Resource executables are signed before app notarization;
package inspection verifies publisher/Gatekeeper, original notice checksums,
source-media/development database exclusion and reports resource/installer sizes.
No remote downloads, publication, source imports or user audio modifications occur.

Release native startup now fails clearly if bundled media are absent rather than
silently using Homebrew or developer environment tools. Development fallback
remains. Settings exposes the absolute installed MCP bridge and discovery path;
no PATH or workspace dependency is claimed for a qualified package.

The supported tester scope requested is macOS, Windows **and** Linux. None has
an installed qualification yet. This partial implementation provides a native
macOS candidate path, while Windows static dependency/certificate packaging and
Linux signed package integration remain blocked/unimplemented. Missing static
FFmpeg inputs, their actual redistribution/source notices and signing identities
prevent a real signed candidate. The manual workflow intentionally stops on
missing inputs; it is not a functioning unattended release until audited input
and certificate provisioning are integrated. Windows/Linux CI is compilation
and fixture evidence only. SS-034 tracks Linux GTK advisory remediation.

Remaining gates: all requested installer architectures/distributions, clean
machine/offline launch without runtimes, actual installed media/MCP operation,
physical listening, extracted package/signature evidence, real package size,
upgrade/uninstall and signed updater acceptance. Automatic updates are disabled;
signed full-installer replacement is documented. No schema changes in this ticket.
