# SS-009 review: Library workspace and accessibility

## Scope

Native catalog workspace connected to Tauri service with production accessibility, independent list/playback state, keyboard navigation, responsive window layouts, screen-reader live announcements, and restrained typography/tokens.

## Acceptance Criteria Verified

- **Bold restrained tokens**: High-contrast, clean dark theme with restrained typography, clear focus indicators (`:focus-visible` 2px solid cyan outline), and zero neon/fake glow elements.
- **Real waveforms**: Measured PCM extrema waveforms drawn accurately via `<canvas role="img" aria-label="Measured audio waveform">` with dynamic DPR scaling and resize observation; no fake activity.
- **No fake activity**: Progress bars and job statuses track real filesystem scanning and background SQLite transactions; AI displays clear "Disabled" provenance.
- **List and active playback independent**: Selection of sounds in the catalog list opens metadata inspection in the inspector panel without overriding the active playing sound in the transport footer. The transport footer tracks `playingSound` or resolves active `playback.sound_id`. Row play/pause buttons reflect individual playback status (`playing`, `paused`, or `stopped`).
- **Keyboard and screen-reader support**:
  - Full keyboard navigation: `ArrowDown` / `j`, `ArrowUp` / `k` for moving through search results; `Enter` to inspect; `Space` to toggle playback (prevented while typing in inputs); `/` to focus search input; `m` to toggle mute; `Escape` to dismiss details inspector, filter popover, relink modal, or error banners; `PageDown` / `PageUp` for 75-item page navigation.
  - Screen reader live region: `<div role="status" aria-live="polite" aria-atomic="true" aria-label="Announcements" className="sr-only">` announcing search hit counts, playback state transitions, filter changes, and metadata save completions.
  - ARIA semantics: `role="listbox"` with `role="option"`, `aria-selected`, `aria-current`, accessible seek/volume sliders with `aria-valuemin`, `aria-valuemax`, `aria-valuenow`, `aria-valuetext`, and `role="meter"` for output peak level.
- **Reduced motion**: Supported via `@media (prefers-reduced-motion: reduce)` disabling all CSS animations and transitions.
- **Tooltips & accessible names**: Clear titles and aria-labels on every icon button and interactive control.
- **Responsive narrow window**: Breakpoints down to 820px and 600px with compact transport wrapping, collapsible sidebar icon rail, and responsive search toolbar.
- **Clear empty/loading/error states**: Dedicated accessible empty states for library search and imports, explicit error banners with dismiss controls, and resilient fallback states.
- **Long sound title truncation**: Row titles and transport titles clamp safely with ellipsis (`overflow: hidden; text-overflow: ellipsis; white-space: nowrap`) without overlapping action buttons or durations.
