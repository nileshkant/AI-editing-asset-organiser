# SS-029: source-folder metadata catalogs

The folder importer now reads `.creativeshelf/catalog.json` before discovery.
A compatible snapshot restores source/sound IDs, measured profiles, annotations,
current recipes and complete clip revision history. A same-library reimport keeps
local edits; stat changes alone enqueue affected members. New members require
Rescan. SQLite remains the query database and originals stay in their source.

Snapshots use a bounded validated schema, relative membership, analyzer version,
stat fingerprints, revision CAS and an OS file lock. Metadata-only writes refuse
to acknowledge changed media. Scan writes verify fingerprints against those
observed during hashing/analysis. Missing members are pruned only after confirmed
absence inside a readable root; DB identity/history remains recoverable. Failed,
incomplete, cancelled and offline operations preserve the prior snapshot.

Schema v7 adds durable dirty/revision/error state and mutation triggers. Stage
files are synced and renamed atomically; directory sync is used on Unix. Local
changes during a snapshot stay dirty. Settings offers retry, confirmed rebuild
with previous JSON backup, and recovery of a malformed pre-import catalog.
Background saves run after source jobs complete, so annotations from UI or MCP
are not stranded in app-only storage. Nonregular files cannot block snapshot
reads, and symlink members/directories are rejected.

## Limits and remaining qualification

Stat equality is a fast-path assumption; same-size/same-timestamp replacement
needs Rescan. Detailed waveform tiles rebuild on demand from the source; import
itself reuses the stored measured profile. AI event provenance awaits the
SS-016/017 versioned contract and is not claimed today. SS-022 must qualify full
backup/restore with snapshot revisions; source-side physical disk-full/power-loss
fault injection and installed-platform checks remain SS-023/031 gates. Read-only
write failures exercise the same staged-write cleanup boundary but are not
reported as a physical disk-full test. No signed release is certified here.
