# SS-079 review: free direct-download public beta

## Changes

- `scripts/unsigned-release.mjs`: versions `X.Y.Z[-alpha|beta|rc.N]`; provenance
  purpose renamed `direct-download-release` (signed/local evidence still rejected).
- `scripts/sign-linux-release.mjs`: detached GPG signatures through the existing
  `release-signing.mjs` helpers, verified against `LINUX_SIGNING_FINGERPRINT`.
- `unsigned-release.yml`: `v*` tags; Linux signing required for non-alpha tags;
  publish job re-verifies every Linux signature against `release/linux-release-key.asc`
  and attaches the key; title, notes and Latest/prerelease chosen per tag kind.
- `docs/RELEASE_NOTES.md`, README, `SECURITY.md`, `docs/RELEASE.md`, `site/`.

## Evidence

- `npx vitest run scripts/`: release script tests pass, including the new
  `sign-linux-release.test.js` name-selection tests. Its GPG round trip is skipped on macOS
  and runs on Linux CI.
- Debian container (`node:24-bookworm`, GnuPG 2.2): documented key recipe produced no
  subkeys; script signed AppImage, deb and checksum list; the workflow's VALIDSIG check
  passed for all three; a modified deb was rejected. The exported private key imported
  into a fresh keyring (the CI secret path) and signed successfully.
- Privacy claims checked in code: the only network listener binds `Ipv4Addr::LOCALHOST`
  (`crates/agent/src/lib.rs`), the bridge accepts only `127.0.0.1`, and no other HTTP
  client exists in the app.

## Known limitations

- macOS Gatekeeper and Windows SmartScreen still ask once (documented in notes and site).
- Only Apple Silicon macOS is built (`macos-14` runner).
- The site screenshot comes from review evidence with fixture titles.
- Pages deployment workflow not yet added (see SS-079 A5).
