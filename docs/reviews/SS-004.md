# SS-004 initial media import increment

Implemented: recursive supported-audio discovery, full-stream decode, bounded real waveform envelope, full-file sample count/peak/RMS, per-file failure isolation, cancellation/timeouts, content checks, cached-profile reuse and conservative deletion reconciliation. Analysis is a blocking service intended to run on the desktop's worker, never the UI thread.

Validation: 29 unit/integration tests passed. Two explicit FFmpeg fixture tests additionally passed: generated 48 kHz audio yielded exactly 12,000 frames; relocation reused its profile with zero reanalysis; deletion marked it missing. A deliberately slow decoder timed out and was reaped. All generated files were isolated temporary fixtures, not user audio.

Review fix: process waiting must not hold the child mutex, or the watchdog cannot terminate a stalled child. Waiting now polls without retaining that lock.

Remaining: durable job queue/recovery, native drag/drop wiring, separate worker process containment, richer per-channel spectral/loudness analysis, multiresolution tiled waveform storage and bundled release-qualified media binaries. Initial waveform combines channel extrema, not a stereo downmix; antiphase stereo cannot cancel its measurement. Descriptions intentionally do not claim recognized events. Self-review; no published PR without a remote.
