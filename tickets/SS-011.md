## Working design

Per-channel min/max/RMS pyramid, tiled Canvas rendering and native playback cursor.

## Acceptance criteria

- [ ] Peaks derive from decoded samples.
- [ ] zoom/pan deterministic.
- [ ] stereo separate.
- [ ] selection accessible numerically.
- [ ] cursor matches source frames.
- [ ] caches versioned.
- [ ] no full-file PCM in renderer.

## Test scenarios

- Impulse sample mapping.
- high zoom.
- long files.
- resize/retina.
- missing cache rebuild.
- nonblank pixel test.
- frame drop profiling.

## Review and completion

Review correctness, failure recovery, file safety and privacy. Record commands and actual outcomes in docs/reviews/SS-011.md. Do not mark complete merely because the UI control exists. Record platform limitations and deferred criteria explicitly. Each fix discovered during review remains scoped to this ticket or gets a follow-up ticket/branch.

## Rollout

No source media mutations. Any persistent-schema change requires a transaction, migration test and compatible rollback or pre-migration backup. Feature flags remain off until their acceptance checks pass.
