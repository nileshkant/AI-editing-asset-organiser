## Working design

Audio v1: organized settings, cache/resource controls, database backup/restore
and a redacted support bundle. Provider setup SS-014 is optional and does not
block baseline settings. Distinguish DB backup, source-folder metadata snapshots,
waveform caches and exported audio; diagnostics must not collect source media.

## Acceptance criteria

- [ ] Folders editable.
- [ ] output device and worker limits.
- [ ] AI consent controls only if AI ships; baseline clearly states recognition unavailable without an enabled model.
- [ ] cache rebuild distinct from analysis reset.
- [ ] backup consistent WAL snapshot.
- [ ] destructive actions confirmed.
- [ ] no recordings/keys in diagnostics.

- [ ] Source catalog reuse/refresh/rebuild and read-only/dirty snapshot warnings explained.
- [ ] Backup/restore reconciles source metadata revisions without overwriting newer user annotations.

## Test scenarios

- Restore/version mismatch.
- disk-full backup.
- concurrent jobs.
- settings migration.
- redaction.
- cache purge during playback.
- reset cancellation.

No source media mutations. Any persistent-schema change requires a transaction, migration test and compatible rollback or pre-migration backup. Feature flags remain off until their acceptance checks pass.
