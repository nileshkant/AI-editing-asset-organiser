## Working design

Guarded candidate preparation, audited media staging, installed MCP bridge discovery and artifact inspection. Native candidate tooling exists for macOS/Windows/Linux, with signed-source minimal FFmpeg preparation. Actual installer qualification, signing provisioning and installed evidence remain release gates. See docs/RELEASE.md and docs/reviews/SS-024.md.

## Acceptance criteria

- [ ] macOS/Windows/Linux builds with supported architecture matrix.
- [ ] no external runtime setup by user within qualified baseline.
- [ ] clean installs.
- [ ] audio audible.
- [ ] FFmpeg license/source notices.
- [ ] signed updates.
- [ ] no user media shipped; inspect artifact contents and fail packaging if source recordings/catalogs/dev databases are included.
- [ ] Measure compressed/uncompressed package size per architecture; report media tool/runtime overhead separately from model packs/caches/exports.
- [ ] Install the MCP bridge and test its discovery path independent of workspace/PATH.
- [ ] Lock supported platform matrix to verified artifacts; first tester release may use a smaller explicit matrix.

## Test scenarios

- Clean VMs.
- offline install.
- upgrade/rollback.
- signature checks.
- minimum OS.
- bundle license/SBOM.
- uninstall retains library by default.
- Intel/ARM validation.

## Review and completion

Review correctness, failure recovery, file safety and privacy. Record commands and actual outcomes in docs/reviews/SS-024.md. Do not mark complete merely because the UI control exists. Record platform limitations and deferred criteria explicitly. Each fix discovered during review remains scoped to this ticket or gets a follow-up ticket/branch.

## Rollout

No source media mutations. Any persistent-schema change requires a transaction, migration test and compatible rollback or pre-migration backup. Feature flags remain off until their acceptance checks pass.

unsigned tester prerelease on all three OSes. Separate scripts and provenance
must retain signed production gates. Hosted build/test/extraction/content checks
gate the public download; installed physical/client qualification remains pending.
See `docs/UNSIGNED_TESTER_RELEASE.md` for the public limitations and install guide.
