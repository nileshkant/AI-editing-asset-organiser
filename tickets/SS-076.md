## Required technical behavior

### R1

Extend SS-065 exporter with extraction recipe containing source content/version, mask digest/revision, coordinate transform, original-alpha composition, crop bounds, padding, and output dimensions.

### R2

Default cutout RGB comes from the visible source pixels with documented color conversion; alpha combines original transparency and mask without accidentally making originally transparent pixels opaque.

### R3

Offer tight nonzero-alpha bounds versus preserve source canvas, explicit padding units, and optional resize after masking. Define alpha threshold for bounds and empty/full mask behavior.

### R4

Use correct premultiplied resampling/unpremultiplication so edge halos do not appear; document hidden RGB handling and prevent division by zero.

### R5

Save real RGBA PNG; preview checkerboard is never baked in. Preserve full-resolution mask quality and declared bit-depth/color policy.

### R6

Verify source/mask/recipe versions immediately before render/publication; independently decode staged PNG and compare dimensions, alpha distribution, bounds, and source-pixel fidelity within explicit conversion tolerances.

### R7

Reuse atomic no-clobber export/destination grants, cancellation, journaling, idempotency, and manifest privacy; a completed file remains valid after app quit or source goes offline.

### R8

Add extraction metadata/attribution to manifest and a UI result with actual path, dimensions, alpha state, and optional later registration. Registration is delivered in SS-077.

### R9

Test preservation of existing transparency and soft edges, not only binary cutout silhouettes.

## Failure, boundary, and verification scenarios

- **T1:** Known source/mask golden pixel fixtures, original alpha multiplied by selection, all-transparent/all-opaque masks, padding, odd dimensions, and resize edges.
- **T2:** Stale mask/source, cancel/disk-full/collision/crash/retry through image exporter; unchanged original digest.
- **T3:** Independent-editor compositing over contrasting backgrounds verifies actual alpha, no baked checkerboard, bounds, and visible RGB fidelity.
- **T4:** Apply the shared contract's relevant authorization, concurrency, cancellation, persistence, recovery, resource, and accessibility checks. Record a reason for any genuinely inapplicable category.
- **T5:** Verify impacted legacy audio behavior and ensure original media hashes are unchanged. Use real media/native/client tests for media/platform claims, not mocks alone.
