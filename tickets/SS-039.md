# SS-039: Approved MCP audio import and AI tagging workflow

Status: not-started
Priority: upcoming audio enhancement
Depends on: 014, 016, 019, 037

Image-phase relationship: [SS-068](SS-068.md) implements/reuses native exact
selection-grant and scoped import infrastructure for images. Share that
infrastructure; this ticket's audio recognition and audio-specific acceptance
remain separate. Image import does not imply consent to upload either modality.

Enable the requested AI-client import/tagging workflow after model-backed sound
recognition and provider consent are available. Do not claim current MCP tools
import audio or listen to recordings. This ticket adds no images or presets.

Acceptance:
- Native app approval scopes exact selected files or a folder before an agent
  queues an import; arbitrary tool paths cannot broaden source access.
- Reuse the shared import queue, source catalog, cancellation and missing-file
  rules; never copy originals into the application package.
- Explicit audio-upload/provider consent. Audio-capable inference produces
  specific event labels such as rain, thunder, hiss, footsteps and engine.
- Preserve user tags; record provider/model, content version, confidence and
  provenance. Replacements invalidate stale evidence; failures remain visible.
- Query status/jobs through scoped MCP tools; review, accept or correct tags.
- Real labeled audio fixtures demonstrate recognition quality and searchable
  tags, plus permission, upload-consent, cancellation and stale-version tests.
