## Required technical behavior

### R1

Define image query/filter/result contracts for kind, text, source, effective tags, favorites, rating, dimensions, aspect/orientation, alpha/actual transparency, dates, provenance, usage notes, and analysis/review state.

### R2

Search captions, user notes, OCR, generation metadata only according to field visibility settings; retain exact phrase/tag and exclusion semantics with Unicode/token-boundary handling.

### R3

Treat dimensions/availability/source scope and explicit exclusions as hard predicates. Null/unknown never equals zero, false, or approved.

### R4

Implement deterministic ranking with explicit tier/tie-break rules, bounded pagination and facet counts computed after authorization; document live-page changes or use stable cursors.

### R5

Keep suggested-versus-confirmed tag filters visible; index effective fields transactionally when annotations/evidence change.

### R6

Expose search controls, result explanation, saved image-search schema, clear/reset actions, no-match guidance, and filter-state persistence without leaking private query history.

### R7

Avoid full scans/decodes/hashes on metadata search; build indexes and measure query plans on representative 10k/100k catalogs.

### R8

Preserve legacy audio search contracts and audio ranking; use shared validation where behavior is truly common instead of widening sound-specific inputs.

## Failure, boundary, and verification scenarios

- **T1:** Query matrix covers exact/phrase/exclusion/fuzzy terms, Unicode, aliases, unknowns, numeric boundaries, and absent models.
- **T2:** Unauthorized source IDs cannot affect result counts/facets; missing/failed images excluded from ready selection.
- **T3:** Stable ordering/pagination and immediate update after edits, plus large-library query plans and latency.
- **T4:** Apply the shared contract's relevant authorization, concurrency, cancellation, persistence, recovery, resource, and accessibility checks. Record a reason for any genuinely inapplicable category.
- **T5:** Verify impacted legacy audio behavior and ensure original media hashes are unchanged. Use real media/native/client tests for media/platform claims, not mocks alone.
