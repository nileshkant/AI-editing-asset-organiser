## Required technical behavior

### R1

Add a dedicated image-analysis module; choose pinned maintainable decoder/color dependencies with license notices, supported architectures, and a measured rationale recorded in docs/DECISIONS.md.

### R2

Support still JPEG, PNG, and WebP through content sniffing plus validated decoding; mismatch between extension and decoded type is visible. Reject animated WebP/APNG explicitly for this release rather than silently analyze only one frame.

### R3

Measure raw/oriented dimensions, aspect ratio, encoded byte size, bit depth/color space where available, alpha-channel presence, any transparent pixels, and partial alpha coverage. Full decode is required before technical-ready.

### R4

Normalize EXIF orientation for display; retain original bytes and raw orientation. Define sRGB display conversion, ICC handling, premultiplication, and explicit warnings for unsupported color profiles/high bit depth.

### R5

Enforce compressed size, metadata size, pixel count, decoded buffer, frame count, execution deadline, and worker memory limits before large allocations; checked multiplication for dimensions/strides.

### R6

Hash content in bounded chunks and identify file/source generation changes between open, decode, and publish. Return version-bound analysis; do not claim unchanged content solely from stat metadata.

### R7

Handle corrupt/truncated files, malformed EXIF/ICC, zero dimensions, decompression bombs, read failures, and decoder failures as isolated errors; no panic takes down the service.

### R8

Define cancellation checkpoints, worker supervision/isolation justified by decoder behavior, and explicit unsupported-format errors; decoder processing must not run on the UI thread or hold catalog locks.

## Failure, boundary, and verification scenarios

- **T2:** Test animation rejection, truncated chunks, malicious dimensions, corrupt profiles, extension mismatch, source changes during decode, timeout, and cancellation.
- **T3:** Measure peak memory for admitted maximum fixtures and verify unchanged original hashes.
