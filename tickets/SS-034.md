## Evidence and scope

RustSec audit on 2026-10-02 identifies RUSTSEC-2024-0429 in glib 0.18.5,
an unsound VariantStrIter implementation in the Linux GTK dependency chain.
The published fixed release is glib >=0.20; Tauri's GTK3 chain currently requires
0.18. A provenance-checked two-line upstream backport is now adopted in vendor/glib.
Do not force an incompatible major version or suppress the warning. Optimized Linux
regression and installed platform qualification remain pending.
Linux is excluded from advertised tester platforms until this is resolved and
qualified. macOS/Windows compile tests do not qualify an installed Linux release.

## Acceptance criteria

- [x] Identify complete Linux dependency chain and affected call reachability.
- [x] Adopt a compatible maintained upstream fix or narrowly audited patch.
- [ ] Record patch provenance and license; audit lock and final binary dependencies.
- [ ] Linux native build, hostile metadata, startup, physical playback/MCP and
      clean install/upgrade tests pass on the declared distribution/architecture.
- [ ] Re-run RustSec; remove release block only with a recorded review decision.

Record tests and limitations in docs/reviews/SS-034.md. Unmaintained transitive
proc-macro/unic warnings also require a tracked dependency maintenance decision.
