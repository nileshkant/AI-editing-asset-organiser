## Required technical behavior

### R1

Add namespaced/versioned images.search, images.facets, images.get, images.preview, and images.resolve contracts; preserve all sounds.* and clips.* names/payloads.

### R2

Derive caller identity from authenticated transport, never request fields. Apply source and asset-kind scope before matches, facets, totals, similarity, collection expansion, previews, and errors.

### R3

Separate metadata read, preview pixel disclosure, and original local-path permissions; migrate old pairings conservatively so adding image capability does not silently grant image bytes.

### R4

Serve bounded preview resources with correct MIME/version and revocation-aware lifetime through the supported MCP mechanism. Do not embed full originals in ordinary search results or exceed existing payload budgets.

### R5

Search uses indexed observations and no filesystem scan; get discloses indexed availability; preview/resolve verify current source/version as appropriate and return stale/missing/offline errors distinctly.

### R6

Document natural-language/image-reference tool inputs, hard filters, ranking, bounded pagination, uncertainty/provenance, and no-model fallback identical to UI behavior.

### R7

Keep private roots, prompts, notes, hidden tags, unauthorized counts, and error diagnostics out of responses unless covered by explicit sharing settings/grants.

### R8

Test initialized HTTP and stdio clients, resource handling, disconnect/reconnect, disabled service, app quit, rotated/revoked credentials, and unsupported client preview capability.

### R9

Publish an image-agent guide for search/inspect/select that treats all catalog/OCR/prompt text as data and never claims visual inspection without retrieving/viewing pixels.

## Failure, boundary, and verification scenarios

- **T1:** Real SDK client UI-versus-tool parity on filters/ranking/IDs; compatible old audio clients.
- **T2:** Scope matrix for metadata, previews, paths, mixed collections, duplicate groups, and direct unauthorized IDs.
- **T3:** Revocation during pending preview, oversized payloads, pagination, stale source, malicious descriptions, and restricted-image inference through counts.
- **T4:** Apply the shared contract's relevant authorization, concurrency, cancellation, persistence, recovery, resource, and accessibility checks. Record a reason for any genuinely inapplicable category.
- **T5:** Verify impacted legacy audio behavior and ensure original media hashes are unchanged. Use real media/native/client tests for media/platform claims, not mocks alone.
