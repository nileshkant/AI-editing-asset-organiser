## Required technical behavior

### R1

Extend native file/folder dialogs and drag/drop with image or mixed-source import preview; disclose recursive folder scope, supported/unsupported counts, and reference-in-place behavior.

### R2

Validate native selections and canonical containment; explicit files grant only those files, including selected parent-directory membership records without importing siblings. Symlink escapes and overlapping selections cannot broaden access.

### R3

Dispatch audio/image jobs by verified type; preserve audio job semantics and fairness. Use SS-042 full decode then publish each successful image independently.

### R4

Persist discovery and analysis phases, lease/retry state, cancellation, counters, and per-file sanitized error categories; prevent duplicate concurrent work on identical source generations.

### R5

Handle restart, crash, drive removal, permission changes, incomplete discovery, corrupt files, zero eligible files, duplicate selections, and file replacement during processing.

### R6

Keep technically ready images browsable even before AI exists; never auto-start uploads or model downloads. Pending/failed records live in Imports with retry actions.

### R7

Preserve annotations during reimport and reuse content-version analysis. Do not mass-mark missing files from partial/cancelled discovery.

### R8

Wire typed commands/events through api.ts/types.ts; fence late progress events by job/source generation and debounce UI updates without hiding terminal failures.

### R9

Retain SS-041 feature/sidecar guards until SS-048; use disposable test libraries for gated internal image flows.
