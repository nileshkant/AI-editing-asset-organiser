## Required technical behavior

### R1

Create project identities and revisioned usage events containing asset/content version, derivative/crop recipe revision, export identity, timestamp, and origin.

### R2

Separate exported, shortlisted, and confirmed-used states. App-observed export is not proof that an external editor used a file; manual confirmations or qualified integrations must identify their source.

### R3

Append verified export events only at successful publication; failed/cancelled exports do not count as use, and idempotent retries do not duplicate events.

### R4

Offer per-project assets, per-asset history, last-used filters, and optional avoid-recently-used search hints that can be overridden.

### R5

Retain historical references when originals move/change/disappear; display whether the exported file still exists without silently rewriting history to current bytes.

### R6

Keep private project names/paths out of agent or shared manifests unless authorized; source revocation affects visible history details/counts.

### R7

Define event correction/undo, project rename/archive/delete semantics, retention, and portable/backup behavior. Deleting history never deletes files.

### R8

Add synthetic placeholders for future derivative lineage and record exported digest/dimensions to support exact later recovery.

## Failure, boundary, and verification scenarios

- **T1:** Successful/failed/cancelled/retried exports, manual use confirmations, and conflicting corrections.
- **T2:** Source replacement/offline state, missing exported file, renamed project, and restore.
- **T3:** Privacy-filtered history/facets and no claim of external editor use without evidence.
- **T4:** Apply the shared contract's relevant authorization, concurrency, cancellation, persistence, recovery, resource, and accessibility checks. Record a reason for any genuinely inapplicable category.
- **T5:** Verify impacted legacy audio behavior and ensure original media hashes are unchanged. Use real media/native/client tests for media/platform claims, not mocks alone.
