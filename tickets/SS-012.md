## Working design

Start/end and start+duration selection using source sample frames; non-destructive saved variants.

## Acceptance criteria

- [x] Click start then enter 15 seconds.
- [x] exclusive end and exact rounding documented.
- [x] clamp only with explicit feedback.
- [x] recipes version-bound.
- [x] source replacement flags stale recipes.
- [x] accessible inputs and handles.

## Test scenarios

- Zero/negative/out-of-range/NaN.
- 44.1k and 48k.
- fractional seconds.
- source shortened.
- selection across zoom.
- decimal-string API counters.

## Review and completion
