## Working design

JSON/Markdown exports with relative paths and explicit root mapping; opt-in legacy import.

## Acceptance criteria

- [ ] Catalog usable without rereading audio.
- [ ] schema versioned.
- [ ] roots configurable.
- [ ] no secrets.
- [ ] legacy descriptions labeled inference.
- [ ] old 20-second measurements not full-file facts.
- [ ] annotations retained.

## Test scenarios

- Roundtrip export/import.
- relocate cloud-synced root.
- Unicode.
- missing root.
- unsupported schema.
- legacy count/hash checks.
- no source modification.

## Review and completion

Review correctness, failure recovery, file safety and privacy. Record commands and actual outcomes in docs/reviews/SS-021.md. Do not mark complete merely because the UI control exists. Record platform limitations and deferred criteria explicitly. Each fix discovered during review remains scoped to this ticket or gets a follow-up ticket/branch.

## Rollout

No source media mutations. Any persistent-schema change requires a transaction, migration test and compatible rollback or pre-migration backup. Feature flags remain off until their acceptance checks pass.
