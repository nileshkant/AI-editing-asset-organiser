## Working design

## Acceptance criteria

- [ ] Relinking never changes sound identity.
- [ ] identical content can reuse analysis.
- [ ] schema migration is transactional.
- [ ] path containment enforced.
- [ ] user tags/comments survive restarts and content replacement.

## Test scenarios

- Temp-DB roundtrip.
- migration rollback.
- duplicate sources.
- traversal/Unicode/case paths.
- content changes vs unchanged roots.
