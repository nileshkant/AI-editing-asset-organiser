## Required technical behavior

### R1

Use a versioned allowlisted manifest with model identity, capability, architecture/runtime requirements, trusted origin, expected bytes/digest, license, and storage/RAM guidance.

### R2

Provide explicit download/install/activate/update/uninstall controls with progress, cancellation, disk-space checks, and clear distinction between downloaded, verified, active, failed, and incompatible.

### R3

Verify artifact integrity and authenticity against the trusted manifest before activation; stage atomically, reject path traversal/symlink archives, and never execute untrusted downloaded scripts.

### R4

Bound network concurrency/timeouts, resume only with validated identity/range support, and keep prior working pack until an update commits.

### R5

Handle unsupported CPU/instruction set, absent accelerator, low RAM, unavailable runtime, missing files, and corrupt cache without breaking manual import/search.

### R6

Treat active-pack changes as version changes for queued inference and embedding spaces. Keep existing annotations and derived exports; schedule explicit reindex rather than mixing vectors.

### R7

Prevent uninstall while shared inference retains unowned resources; cancel or drain safely and clean only pack-owned files with usage count and storage summary.

### R8

Reuse SS-017 pack-management code if present and update its shared-component evidence links. Audio model evaluation remains outstanding.

## Failure, boundary, and verification scenarios

- **T1:** Corrupt digest, truncated download, malicious archive, redirect changes, disk-full, cancellation/restart, and incompatible architecture fixtures.
- **T2:** Update/rollback/uninstall during queued or running jobs; offline startup with installed versus absent pack.
- **T3:** Real inference using the packaged runtime on supported hardware and no development-tool dependency.
- **T4:** Apply the shared contract's relevant authorization, concurrency, cancellation, persistence, recovery, resource, and accessibility checks. Record a reason for any genuinely inapplicable category.
- **T5:** Verify impacted legacy audio behavior and ensure original media hashes are unchanged. Use real media/native/client tests for media/platform claims, not mocks alone.
