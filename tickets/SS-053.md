## Required technical behavior

### R1

Invoke SS-050 adapters through SS-052 only; bind request to actual decoded/preprocessed pixels and retain preprocessing/coverage metadata.

### R2

Validate bounded structured output for subject/object, scene, action, style, mood, lighting, palette, and composition suggestions plus editable caption.

### R3

Separate observed technical facts, model interpretations, filename hints, imported claims, and user annotations. No inference of exact generator, real-person identity, legal rights, hidden object parts, or unsupported precision.

### R4

Normalize display tags/aliases without collapsing distinct meanings; preserve raw evidence only in bounded sanitized storage where needed for debugging, never as executable content.

### R5

Persist provider/model/revision, input content hash, schema/preprocessor version, timestamp, uncertainty representation, and analysis coverage. New model output creates new evidence rather than overwriting accepted human facts.

### R6

Handle invalid/empty/partial output, unsupported categories, hallucination, mixed subjects, unknowns, and duplicates with structured failures or explicitly partial enrichment status.

### R7

Publish analysis atomically after current-content and consent checks; update dirty snapshots and add fields to portable import/export/backup round trips.

### R8

Expose generation status and provenance in inspector with a manual retry entry; technically ready images remain usable if enrichment fails.

At this point, expose typed evidence to catalog reads and the inspector.
Searchable-field definitions are prepared here; full text/filter UI and query
indexing are delivered in SS-058, not required from that later ticket now.

### R9

Re-run held-out tagging/caption evaluation through the production pipeline rather than only the evaluation adapter.

## Failure, boundary, and verification scenarios

- **T1:** Real model fixtures and labeled corpus validate actual image understanding; mocks cover error parsing only.
- **T2:** Test malformed responses, nonfinite scores, enormous captions/tags, malicious text, same-stat content change, and cancellation before publication.
- **T3:** Round-trip evidence through sidecars/portable catalogs and ensure reanalysis never modifies user annotations.
- **T4:** Apply the shared contract's relevant authorization, concurrency, cancellation, persistence, recovery, resource, and accessibility checks. Record a reason for any genuinely inapplicable category.
- **T5:** Verify impacted legacy audio behavior and ensure original media hashes are unchanged. Use real media/native/client tests for media/platform claims, not mocks alone.
