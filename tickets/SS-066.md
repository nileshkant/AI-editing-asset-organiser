## Required technical behavior

### R1

Add export UI for original versus transformed, crop, dimensions, format/quality, alpha/matte preview, metadata policy, destination choice, and manifest inclusion.

### R2

Show resolution/suitability warnings and stale recipe recovery before submission; preserve settings while navigating and keep export progress independent of current selection.

### R3

Use native single-file destination grants and SS-065 engine; cancellation/retry reflects publication boundary and cannot delete a completed export.

### R4

Implement native drag-out only for materialized valid exports where OS support is qualified; provide explicit save/reveal/copy-path fallback on every supported platform.

### R5

Extend generic editor/Remotion handoff utility to image assets in an explicitly selected project location; validate project-relative paths, Unicode/URL encoding, filename collisions, and missing files.

### R6

Do not require SS-033 presets, automatically execute editor code, change project dependencies, or claim the editor opened the file without evidence.

### R7

Document rendered media remains usable after app exit and distinguish manifest metadata from media files required by the project.

### R8

Add accessible forms, progress announcements, keyboard/numeric controls, and clear destination/permission errors.

## Failure, boundary, and verification scenarios

- **T1:** Native save and actual external-editor import of alpha/cropped/original images; Remotion fixture renders from handed-off image.
- **T2:** Drag supported/unsupported platforms, app exit, missing project directory, special-character paths, and collision.
- **T3:** UI preview-to-output dimensions/matte agreement, cancellation/retry, and audio handoff regression.
- **T4:** Apply the shared contract's relevant authorization, concurrency, cancellation, persistence, recovery, resource, and accessibility checks. Record a reason for any genuinely inapplicable category.
- **T5:** Verify impacted legacy audio behavior and ensure original media hashes are unchanged. Use real media/native/client tests for media/platform claims, not mocks alone.
