## Required technical behavior

### R1

Generate thumbnail tiers and bounded full-inspection previews from SS-042 oriented/color-managed decoding. Key caches by content digest, preprocessing version, size tier, and color policy.

### R2

Use atomic temporary writes and validated dimensions/mime; concurrent requests coalesce. Cache repair never modifies originals or recomputes user annotations.

### R3

Expose an asset-ID/version preview service, not a raw file-path URL. Resolve containment and current permission before reading or serving; no general filesystem protocol expansion.

### R4

Set cache disk quota, LRU eviction, bounded decode concurrency, cancellation when views disappear, and cleanup of only owned temporaries.

### R5

Distinguish original unavailable from cached preview available. Permit local offline reference previews when authorized, but label them and do not imply export is possible.

### R6

Fence stale responses after rapid selection/source relink; invalidate replaced content and changed preprocessing, and avoid serving another asset after ID/version mismatch.

### R7

Use actual alpha for transparent previews; checkerboard is a UI background, never baked into reusable media.

### R8

Add cache size/rebuild controls and diagnostic counts without dumping source paths/media bytes or clearing analysis unnecessarily.

## Failure, boundary, and verification scenarios

- **T1:** Verify known-size/color/orientation/alpha thumbnail fixtures and bounded full-resolution zoom requests.
- **T2:** Test corrupt cache, partial write, disk-full, eviction while previewing, duplicate requests, restart cleanup, and original replacement.
- **T3:** Attempt traversal, unauthorized ID/path access, revoked source, and stale version; measure repeated browse cache reuse.
- **T4:** Apply the shared contract's relevant authorization, concurrency, cancellation, persistence, recovery, resource, and accessibility checks. Record a reason for any genuinely inapplicable category.
- **T5:** Verify impacted legacy audio behavior and ensure original media hashes are unchanged. Use real media/native/client tests for media/platform claims, not mocks alone.
