## Required technical behavior

### R1

Add version-bound composition suggestions for subject regions, focal points, and empty space, produced by a qualified detector/analyzer through existing consent infrastructure.

Qualify this composition adapter here using the existing evaluation harness,
or use a previously qualified analyzer that supplies these fields. Do not
depend on SS-073 segmentation: composition boxes and focal points precede,
and do not implement, interactive object extraction.

### R2

Separate inferred layout from measured aspect ratio and user-confirmed focal points. Store model/coordinates/uncertainty and allow override or unknown.

### R3

Implement 9:16, 16:9, 1:1 and custom-ratio crop previews with fit/fill behavior, target resolution, safe-area overlay, and user-adjustable focal position.

### R4

Use SS-040 canonical coordinates and checked arithmetic; define pixel rounding, bounds, resize/no-upscale defaults, orientation transforms, and edge inclusion precisely.

### R5

Persist crop recipes with asset/content version, revision, rectangle, output intent, and manual focal-point state. Source changes mark recipes stale; explicit rebind requires preview.

### R6

Warn on cropped selected subjects or insufficient native resolution, without guaranteeing the detector found all subjects.

### R7

Support keyboard/numeric crop adjustment, zoom/pan coordinate mapping, undo/redo, and accessible controls.

### R8

Extend source/portable serialization and add structured composition filters after validation; export rendering waits for SS-065.

## Failure, boundary, and verification scenarios

- **T1:** Known rectangles across EXIF orientations, odd dimensions, edges, fractional scales, and target ratios with independent expected pixel bounds.
- **T2:** Subject partly outside crop, no detected subject, unknown empty space, source replacement, and stale recipe rebind.
- **T3:** Keyboard/high-DPI preview and round-trip recipe persistence; no original modification.
- **T4:** Apply the shared contract's relevant authorization, concurrency, cancellation, persistence, recovery, resource, and accessibility checks. Record a reason for any genuinely inapplicable category.
- **T5:** Verify impacted legacy audio behavior and ensure original media hashes are unchanged. Use real media/native/client tests for media/platform claims, not mocks alone.
