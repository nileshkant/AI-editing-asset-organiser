## Working design

Audio v1 requires generic file handoff, a portable Remotion audio manifest and
agent instructions against the installed MCP bridge. Direct Resolve automation
is a post-v1 optional adapter with independent capability verification. Remotion
preset assets belong to upcoming SS-033, not this audio handoff ticket.

## Acceptance criteria

- [ ] Manual files always available.
- [ ] Remotion paths portable.
- [ ] Optional Resolve adapter deferred/disabled for baseline v1; capability checked at runtime if shipped.
- [ ] no universal editor promise.
- [ ] agent skill teaches search then preview then export with evidence and source license.

## Test scenarios

- Manifest resolution after relocation.
- editor unavailable.
- unsupported Resolve edition.
- MCP skill walkthrough.
- no untrusted shell fragments.

## Review and completion

Review correctness, failure recovery, file safety and privacy. Record commands and actual outcomes in docs/reviews/SS-020.md. Do not mark complete merely because the UI control exists. Record platform limitations and deferred criteria explicitly. Each fix discovered during review remains scoped to this ticket or gets a follow-up ticket/branch.

## Rollout

No source media mutations. Any persistent-schema change requires a transaction, migration test and compatible rollback or pre-migration backup. Feature flags remain off until their acceptance checks pass.
