## Working design

Native file/folder drop, explicit recursive import and durable bounded worker jobs.

## Acceptance criteria

- [ ] Pending/failed media never appears as ready.
- [ ] work runs off UI thread.
- [ ] cancellation/retry/progress works.
- [ ] full decode required.
- [ ] corrupt media isolated.
- [ ] no sibling import for individual files.
- [ ] jobs resume after crash.

## Test scenarios

- Nested folders.
- large collections.
- corrupt/truncated audio.
- file changing mid-read.
- cancel/restart.
- worker crash.
- resource budget.

## Review and completion
