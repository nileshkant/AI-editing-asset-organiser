## Working design

Native file/folder drop, explicit recursive import and durable bounded worker jobs.

## Acceptance criteria

- [x] Pending/failed media never appears as ready.
- [x] work runs off UI thread.
- [x] cancellation/retry/progress works.
- [x] full decode required.
- [x] corrupt media isolated.
- [x] no sibling import for individual files.
- [x] jobs resume after crash.

## Test scenarios

- Nested folders.
- large collections.
- corrupt/truncated audio.
- file changing mid-read.
- cancel/restart.
- worker crash.
- resource budget.
