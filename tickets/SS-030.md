## Working design

Audio v1 requirement. Use CreativeShelf as the generic working product name.
The 2026-10-02 review changes the sidebar, page/window title, bundle product name,
visible desktop/MCP errors and current user guidance. Internal Rust crate names,
legacy app identifier/data paths, MCP executable/environment keys and existing
portable/export schemas currently remain compatibility identifiers. Renaming
those without migration would risk abandoning catalogs or breaking integrations.

Do not implement image or preset functionality here. New product terminology
must accommodate assets while audio-specific controls remain precise.

## Acceptance criteria

- [x] Current UI/window/bundle display name is CreativeShelf.
- [ ] Installed package, executable/tray metadata, icon and native dialogs consistently use generic branding.
- [x] Audit visible MCP server metadata and generated client configuration; preserve or migrate existing connections.
- [x] Adopt/document final app ID and data/log paths with collision-safe migration and rollback from existing installations.
- [x] Old database, backup, catalog schema, export manifests and bridge configuration remain readable.
- [x] Current user documentation consistently names CreativeShelf; historical evidence retains its original context.
- [ ] Installed upgrade preserves sources, annotations, clips, settings and paired-client behavior.

## Test scenarios

Frontend branding tests and build; inspect actual package metadata; upgrade a
populated legacy installation and restart; old catalog roundtrip; old/new MCP
configuration; rollback; both data locations present. Record compatibility
aliases explicitly rather than bulk-renaming persisted identifiers.

## Review and completion

Record evidence and limitations in docs/reviews/SS-030.md. Mark acceptance
only after verification. Source audio bytes must never be changed. Schema or
identity changes require transactional migration and recovery evidence.
