## Working design

Streaming decoder, bounded PCM buffer and native output with volume, seeking and pause.

## Acceptance criteria

- [ ] Audible WAV/MP3 output.
- [ ] no web audio dependency.
- [ ] no blocking allocations/locks in callback.
- [ ] transport survives filtering.
- [ ] natural end and device failure visible.
- [ ] no deletion on decode error.

## Test scenarios

- Recorded output/loopback.
- pause/resume.
- seek spam.
- long-file bounded memory.
- unplug device.
- sample-rate changes.
- underruns.
- app quit cleanup.

## Review and completion

Review correctness, failure recovery, file safety and privacy. Record commands and actual outcomes in docs/reviews/SS-010.md. Do not mark complete merely because the UI control exists. Record platform limitations and deferred criteria explicitly. Each fix discovered during review remains scoped to this ticket or gets a follow-up ticket/branch.

## Rollout

No source media mutations. Any persistent-schema change requires a transaction, migration test and compatible rollback or pre-migration backup. Feature flags remain off until their acceptance checks pass.
