in the SS-052 PR were cancelled before startup. See the [runner retirement
notice](https://github.com/actions/runner-images/issues/13518) and the
[predecessor check evidence](../docs/reviews/SS-053.md).

Use the standard `macos-15` arm64 runner for the Verify and Minimal media
qualification workflows. Run both suites on the merged SS-052 source in
this CI-only PR to replace the missing evidence.

also updates the pinned `url` crate from 2.5.8 to 2.5.9. The first
hosted advisory run flagged [RUSTSEC-2026-0592](https://rustsec.org/advisories/RUSTSEC-2026-0592.html).
Cargo also updated `form_urlencoded` to 1.2.3 as required by `url` 2.5.9.

and confirmed the expected macOS, Windows, and Linux matrix. `git diff --check`
passed. Hosted execution is the acceptance test for this runner change.

--locked --test ai_provider --test model_packs --test image_enrichment`
passed all 55 tests on macOS arm64.
