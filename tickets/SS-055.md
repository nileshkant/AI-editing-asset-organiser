## Required technical behavior

### R1

Parse a documented allowlist of generation metadata formats from supported JPEG/PNG/WebP containers and explicitly selected/authorized sidecars; record parser/source/version.

### R2

Map prompt, negative prompt, generator/model identifier, seed as lossless text where large, sampler/settings, generation date/time-zone uncertainty, and reference identifiers.

### R3

Store unknown separately from empty, imported claim separately from user confirmation, and unsupported structured fields as bounded uninterpreted data only when useful.

### R4

Never infer exact prompt/model/seed or AI origin from pixels; do not fetch arbitrary URLs, execute embedded workflows, or follow paths outside selected source scope.

### R5

Expose manual entry/correction, origin visibility, search indexing policy, and opt-in inclusion/redaction of prompts on shared exports.

### R6

Limit metadata decompression, nesting, field lengths, sidecar count, and parser CPU. Decode/analysis readiness must survive malformed optional metadata.

### R7

Update metadata on changed file versions without replacing user-authored provenance; detect sidecar-only changes explicitly with versioned evidence.

### R8

Preserve provenance through portable/source catalogs and later derivatives; private references and local paths need redaction.

## Failure, boundary, and verification scenarios

- **T1:** Known metadata variants, huge/string seeds, malformed JSON/chunks, Unicode prompts, empty/absent fields, and unknown generator.
- **T2:** Hostile workflow content, URL/path references, unauthorized sibling sidecar, and optional parser failure.
- **T3:** Manual edits and redacted/nonredacted portable round-trips; no network request from metadata parsing.
- **T4:** Apply the shared contract's relevant authorization, concurrency, cancellation, persistence, recovery, resource, and accessibility checks. Record a reason for any genuinely inapplicable category.
- **T5:** Verify impacted legacy audio behavior and ensure original media hashes are unchanged. Use real media/native/client tests for media/platform claims, not mocks alone.
