## Required technical behavior

### R1

Extend relink/availability checks to image sources using stable source IDs and generations; unchanged content retains asset identity and analysis.

### R2

Implement explicit Refresh discovery versus listed-file checks; offer exact-byte verification separately where size/mtime cannot prove freshness.

### R3

Add opt-in per-folder watchers with bounded event queues, debouncing, write-stability delay, coalescing, and overflow-to-safe-refresh recovery; exact-file sources never watch siblings.

### R4

Keep root offline, member missing, access denied, decoder failure, and partially completed scans distinct. Prune visible ready results only for confirmed missing members after complete discovery.

### R5

Invalidate previews/technical/AI evidence and recipes when content changes; preserve creator annotations and previous-version recovery history.

### R6

Treat ambiguous renames/overlapping relinks as reconciliation rather than content-hash identity merging. Case-only rename and OS path-case behavior require explicit handling.

### R7

Prevent processing app-owned sidecars, caches, staging outputs, and export loops; intentionally importing a final exported asset uses explicit registration/deduplication rules.

### R8

Stop/restart watchers with app/source lifecycle; show source status and retry actions, and fence in-flight work when source generation changes.

## Failure, boundary, and verification scenarios

- **T1:** External-drive disconnect/reconnect, missing files, permissions, rapid saves, temp-file rename, watcher overflow, and same-stat changed bytes.
- **T2:** Relink identical/changed/ambiguous folders and case-only paths on relevant filesystems; verify no annotation or audio ID loss.
- **T3:** Test mixed folders and future export-like staging names for loops; exact-file watcher scope must remain narrow.
- **T4:** Apply the shared contract's relevant authorization, concurrency, cancellation, persistence, recovery, resource, and accessibility checks. Record a reason for any genuinely inapplicable category.
- **T5:** Verify impacted legacy audio behavior and ensure original media hashes are unchanged. Use real media/native/client tests for media/platform claims, not mocks alone.
