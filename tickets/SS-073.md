## Required technical behavior

### R1

Evaluate point/box-guided segmentation on licensed/consented creator images with multiple subjects, illustration, thin structures, fur/hair, soft edges, overlapping objects, and translucent material.

### R2

Separately evaluate binary/soft masks and alpha matting; segmentation scores are not finished transparency quality. Record unsupported difficult cases and manual refinement needs.

### R3

Verify current model/runtime licenses, redistribution/download terms, native integration, OS/CPU/accelerator support, disk size, peak RAM/VRAM, cold load, interactive latency, and fallback.

### R4

Define canonical input/output adapter contracts for image content/version, preprocessing transform, positive/negative points, boxes, mask logits/probabilities, dimensions, and model revision.

### R5

Integrate qualified packs/providers into SS-049/051/052 infrastructure with explicit download/upload consent and no arbitrary remote fallback.

### R6

Use versioned reusable image embeddings/session cache bounded by active source/content/model; cancel or invalidate after source changes and fence delayed results.

### R7

Freeze meaningful mask/edge quality and latency/resource targets before held-out evaluation; record an actual pass/fail rather than model marketing claims.

### R8

Implement a small production adapter plus reproducible harness, supporting deterministic synthetic adapter fixtures for UI tests and real inference for quality evidence.

### R9

State that extracting visible pixels does not reconstruct occluded body parts, remove objects from the source background, or generate new art.

## Failure, boundary, and verification scenarios

- **T1:** Held-out multi-object selection, soft-edge/matting fixtures, tiny objects, transparent/blank images, and negative-point corrections.
- **T2:** Model absent/corrupt/incompatible, device memory exhaustion, timeout/cancel, source replacement, and cache eviction.
- **T3:** Measure actual native packaged-runtime feasibility and bound model output sizes/nonfinite/invalid masks.
- **T4:** Apply the shared contract's relevant authorization, concurrency, cancellation, persistence, recovery, resource, and accessibility checks. Record a reason for any genuinely inapplicable category.
- **T5:** Verify impacted legacy audio behavior and ensure original media hashes are unchanged. Use real media/native/client tests for media/platform claims, not mocks alone.
