## Required technical behavior

### R1

Add asset-kind navigation and image grid backed by paginated image APIs; preserve audio list, player state, keyboard bindings, and selection when switching views.

### R2

Implement adjustable thumbnail size, virtualization/windowing, deterministic sort with ID tie-breaker, and selection persistence independent of current page/filter.

### R3

Add inspector with technical facts, filename/source, availability, enrichment state, and large preview; support fit, 100%, zoom/pan, and side-by-side comparison of bounded candidates.

### R4

Label alpha/transparency accurately; allow checkerboard/light/dark preview backgrounds without editing images.

### R5

Handle no sources, no supported images, queued import, partial failure, unavailable originals, stale previews, and cache rebuild with useful actions and no false ready state.

### R6

Provide accessible grid semantics, keyboard navigation, focus restore after closing inspector, escape handling, tooltips, screen-reader descriptions, and reduced motion.

### R7

Cancel obsolete loads and revoke owned preview handles; avoid unbounded image elements/buffers or accidental selection changes caused by late responses.

### R8

Validate 720x560 minimum, existing larger layouts, long paths/tags, 200% text scale, high DPI, and loading during background import.

## Failure, boundary, and verification scenarios

- **T1:** Test rapid scrolling/filter changes, source disappearance, stale preview replies, multi-selection, and switching to audio playback.
- **T2:** Browser checks at supported viewport sizes with keyboard and accessibility tooling; native preview test on target OS.
- **T3:** Benchmark visible image count, memory and scroll responsiveness on a representative large synthetic library.
- **T4:** Apply the shared contract's relevant authorization, concurrency, cancellation, persistence, recovery, resource, and accessibility checks. Record a reason for any genuinely inapplicable category.
- **T5:** Verify impacted legacy audio behavior and ensure original media hashes are unchanged. Use real media/native/client tests for media/platform claims, not mocks alone.
