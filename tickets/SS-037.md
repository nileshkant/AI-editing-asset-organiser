# SS-037: Persistent MCP credentials and startup

Status: in-review
Branch: feat/SS-037-persistent-mcp
PR: https://github.com/nileshkant/AI-editing-asset-organiser/pull/35
Depends on: 018, 019, 036

Keep per-client bearer credentials and scoped grants across app restarts. First
Start enables startup with the app on the remembered endpoint. Stop disables
startup and retains pairings. Quit closes the listener without disabling startup.
Rotate explicitly replaces one credential; revoke permanently removes a client.
Persist hashes in a separate local SQLite store, never in portable catalogs.

- [x] Real SDK reconnect with unchanged token and endpoint after restart.
- [x] Rotation invalidates old tokens/sessions; revocation survives restart.
- [x] Stop disables startup; shutdown preserves enabled state.
- [x] Occupied port and corrupt storage fail visibly without credential resets.
- [x] Failed persistence preserves prior credentials and startup state.
- [ ] Exact PR cross-platform CI and installed-client restart check.

Existing alpha.5 pairings were memory-only and cannot survive its first upgrade;
pair once on the updated build. Tests use disposable stores and local clients.
