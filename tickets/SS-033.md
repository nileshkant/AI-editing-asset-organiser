## Working design

Future asset type: versioned Remotion Studio presets with tags, preview metadata,
compatible runtime/version requirements, referenced dependencies and import/export
contracts. SS-020 hands off audio to editors; it does not implement presets.
No preset execution, preset browser or preset storage ships in audio v1.

## Acceptance criteria

- [ ] Preset schema and dependency/license/version compatibility are defined.
- [ ] Tags/search/preview and MCP discovery use authorized common asset services.
- [ ] Portable folder metadata and migrations preserve existing audio/image assets.
- [ ] Untrusted presets never execute automatically merely because they are imported.
- [ ] Missing dependencies, unsupported runtime and relocated presets report actionable errors.

## Review and completion

Record evidence and limitations in docs/reviews/SS-033.md. Mark acceptance
only after verification. Source audio bytes must never be changed. Schema or
identity changes require transactional migration and recovery evidence.
