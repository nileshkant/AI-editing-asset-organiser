## Outcome and necessity

Publish CreativeShelf to the public from GitHub Releases without app stores,
paid certificates or hosting costs, and make the download read as a trustworthy
open-source product rather than an internal tester preview.

Decided 18 October 2026: no Apple Developer Program fee for now (macOS stays
ad-hoc signed and Gatekeeper asks once); Windows applies to the free SignPath
Foundation programme; Linux uses free GPG signatures.

## Requirements

- R1. Tags `vX.Y.Z-beta.N`, `vX.Y.Z-rc.N` and `vX.Y.Z` publish normal releases shown
  as Latest, so `releases/latest` links work. Alpha tags remain tester prereleases.
- R2. Public Linux AppImage, deb and checksum list carry detached GPG signatures.
  Publication fails closed unless each verifies against the committed public key.
- R3. Public release notes explain downloads, the one-time first-launch confirmation
  per OS, verification, privacy and beta limits in plain language.
- R4. README leads with download, first launch and privacy; `SECURITY.md` gives a
  private reporting route and verifiable claims.
- R5. A static download page in `site/` picks the visitor's installer from the
  latest release and still works when the GitHub API is unavailable.
- R6. Internal identifiers (`app.soundshelf.desktop`, data directories,
  `.soundshelf.json`, `soundshelf-mcp`) stay unchanged so existing users keep their data.
