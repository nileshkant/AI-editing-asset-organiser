## Required technical behavior

### R1

Integrate the SS-050 qualified text-image embedding model with SS-051 pack/provider lifecycle and SS-052 bounded jobs; embed actual pixels with pinned preprocessing.

### R2

Key vectors by content/model revision/tokenizer/preprocessing/dimension/normalization and define vector-space identity. Never compare incompatible spaces.

### R3

Build an indexed retrieval layer appropriate to the SQLite/native architecture, with measured rationale and bounded memory/disk; no unexamined external service dependency.

### R4

Apply authorization/hard predicates before final scoring/counts. If ANN filtering underfills results, use bounded overfetch/exact fallback or report incomplete coverage, never include disallowed items.

### R5

Define lexical/semantic hybrid ranking, query interpretation/explanation, threshold/no-good-match behavior, deterministic tie-breaks, and partial embedding coverage visibility.

### R6

Reindex via side-by-side generations and atomic activation; interrupted rebuild leaves the previous index usable. Delete stale vector references and rebuild caches without deleting user metadata.

### R7

Handle model absent/offline, unsupported language, changing provider/vector dimensions, stale content, invalid vectors/NaN, and limited query budget with lexical fallback visibly labeled.

### R8

Preserve source-scope privacy when shared content vectors are reused and document which vector caches are excluded from portable metadata.

### R9

Evaluate held-out creator queries and inspect exact filter accuracy through production indexing, not just a model demo.

## Failure, boundary, and verification scenarios

- **T1:** Ground-truth retrieval queries with strict dimensions/alpha/source constraints; compare against SS-058 baseline.
- **T2:** Mixed vector spaces, corrupt index, restart mid-rebuild, partial coverage, removed model, and changed source versions.
- **T3:** Unauthorized counts/nearest neighbors must not leak; benchmark memory, p50/p95 search, and indexing throughput on declared hardware.
- **T4:** Apply the shared contract's relevant authorization, concurrency, cancellation, persistence, recovery, resource, and accessibility checks. Record a reason for any genuinely inapplicable category.
- **T5:** Verify impacted legacy audio behavior and ensure original media hashes are unchanged. Use real media/native/client tests for media/platform claims, not mocks alone.
