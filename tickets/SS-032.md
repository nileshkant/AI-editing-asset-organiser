## Working design

Add individual images and reusable image elements with stable source references,
portable metadata, manual and AI tags, visual/semantic discovery, creator
collections, project handoff, authorized MCP access, and finally object selection,
mask refinement, transparent PNG export, and derived-element reuse. Preserve the
existing audio baseline and immutable originals throughout.

## Acceptance criteria

- [ ] Asset-kind contract extends identity, source membership, provenance and search without invalidating audio IDs/clips or catalogs.
- [ ] Image/element import, thumbnail caches, dimensions/transparency and source availability supported.
- [ ] Human tags and optional consented AI suggestions support image/element discovery.
- [ ] Mixed asset search/MCP scopes and folder catalogs preserve type-specific metadata.
- [ ] Malformed/oversized image, licensing provenance, missing files and migration tests pass.
- [ ] SS-040–048: typed compatibility, migrations, decode/import, previews/UI,
      manual annotations, source lifecycle, and mixed persistence verified.
- [ ] SS-049–057: qualified optional AI, consent/budgets, durable corrections,
      generation/source provenance, and OCR verified.
- [ ] SS-058–064: strict and semantic/reference search, composition/crops,
      variations, collections/kits, and output suitability verified.
- [ ] SS-065–071: verified image export/editor handoff, scoped MCP read/write,
      shortlists, project usage, and portable media packs verified.
- [ ] SS-072: exact installed candidate passes discovery-to-handoff qualification.
- [ ] SS-073–077: selected-object extraction, refined soft masks, actual PNG alpha,
      and searchable derived lineage verified without reconstructing hidden pixels.
- [ ] SS-078: final installed regression/quality/accessibility/security evidence
      qualifies all advertised image and element capabilities.
- [ ] All 39 child tickets are reviewed and merged, with no required unchecked
      acceptance hidden by a summary status or an unsupported platform claim.
