## Working design

Future creative asset type: individual images and reusable image elements with
source references, portable metadata, tags, collections, previews and authorized
MCP discovery. No image decoding, UI or schema change ships in audio v1.

## Acceptance criteria

- [ ] Asset-kind contract extends identity, source membership, provenance and search without invalidating audio IDs/clips or catalogs.
- [ ] Image/element import, thumbnail caches, dimensions/transparency and source availability supported.
- [ ] Human tags and optional consented AI suggestions support image/element discovery.
- [ ] Mixed asset search/MCP scopes and folder catalogs preserve type-specific metadata.
- [ ] Malformed/oversized image, licensing provenance, missing files and migration tests pass.

## Review and completion

Record evidence and limitations in docs/reviews/SS-032.md. Mark acceptance
only after verification. Source audio bytes must never be changed. Schema or
identity changes require transactional migration and recovery evidence.
