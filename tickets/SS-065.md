## Required technical behavior

### R1

Add original-byte copy and transformed PNG/JPEG/WebP exports with allowlisted format/options, recipe revision, dimensions, color policy, metadata stripping, and explicit destination grant.

### R2

Reuse native export staging/journal/no-clobber principles, not audio encoding assumptions. Hash/validate current source before publication and recheck source generation/destination grant.

### R3

Render SS-061 crop/resize recipes with identical coordinate rounding. Default no upscaling unless explicit; select resampling and alpha premultiplication policy and test against reference pixels.

### R4

PNG/WebP preserve supported alpha; JPEG cannot: require an explicit matte/color preview or reject alpha loss rather than silently flatten. Define bit-depth/profile conversion.

### R5

Original-copy mode preserves bytes including metadata and warns accordingly; transformed/share modes can strip sensitive EXIF/prompts and carry selected provenance in an adjacent manifest.

### R6

Bound decode/encode/output bytes and workers; cancellation, shutdown, disk-full, permission loss, drive removal, filename collisions, and unsupported atomic-filesystem behavior leave existing outputs intact.

### R7

Verify staged output with an independent decode for type, dimensions, alpha, and expected recipe; commit media/manifest with recovery journal and report any post-publication indexing warning separately.

### R8

Ensure retries return one logical output per stable operation key; define idempotency persistence/lifetime and cancellation-versus-publication race semantics.

### R9

Emit typed jobs/results and sanitized errors with verified final paths, bytes, digest, dimensions, and source/recipe version. No success before actual publication.

## Failure, boundary, and verification scenarios

- **T1:** Golden crop/orientation/color/alpha exports; round-trip all formats and verify independent decoder outputs.
- **T2:** Collision/symlink destination, replaced source during render, disk-full, cancelled stages, crash around media/manifest commit, and uncertain retry.
- **T3:** Real export fixtures and unchanged originals; audio WAV/FLAC regression and no output import loop.
- **T4:** Apply the shared contract's relevant authorization, concurrency, cancellation, persistence, recovery, resource, and accessibility checks. Record a reason for any genuinely inapplicable category.
- **T5:** Verify impacted legacy audio behavior and ensure original media hashes are unchanged. Use real media/native/client tests for media/platform claims, not mocks alone.
