## Required technical behavior

### R1

Select and qualify an OCR path using SS-050/051/052 capability infrastructure; record supported languages, layout limitations, preprocessing, and model versions.

### R2

Store recognized text, reading-order/region data in canonical coordinates where available, language, uncertainty, and editable correction layer independently from visual captions.

### R3

Offer explicit analysis options and batch status; cloud OCR must reuse source upload consent and budget rules.

### R4

Validate region bounds, text lengths, total tokens, and structured output; preserve actual generated gibberish as uncertain text rather than normalize it into invented phrases.

### R5

Add optional contains-text, watermark, or logo suggestions only when evaluated; absence of detection must never become a certified no-text/no-logo property.

### R6

Expose review/correction/dismissal and future search fields; changes invalidate OCR-derived indexes and extend source/portable persistence.

Until SS-058 creates full image search, test the typed searchable projection
and invalidation events without depending on a future search UI.

### R7

Treat all OCR content as untrusted text, never as agent instructions, URLs to fetch, code, or commands.

### R8

Measure rotated, low-contrast, stylized, multilingual, small, and repeated text cases; show unsupported/unknown language rather than claim universal OCR.

## Failure, boundary, and verification scenarios

- **T1:** Ground-truth fixtures for intended languages, empty-text images, rotated text, confusable characters, and generated illegible text.
- **T2:** Prompt-injection text embedded in images stays inert; extreme region/text count rejected.
- **T3:** Correction/reanalysis persistence, consent denied, quota failure, and stale version tests.
- **T4:** Apply the shared contract's relevant authorization, concurrency, cancellation, persistence, recovery, resource, and accessibility checks. Record a reason for any genuinely inapplicable category.
- **T5:** Verify impacted legacy audio behavior and ensure original media hashes are unchanged. Use real media/native/client tests for media/platform claims, not mocks alone.
