## Required technical behavior

### R1

Accept a library asset ID/version or a native-picked reference file grant; do not accept arbitrary filesystem paths or fetch remote URLs from metadata.

### R2

Reuse qualified embeddings and optionally measured palettes; expose subject/style/palette weighting only if independently evaluated, otherwise label generic visual similarity honestly.

### R3

Use source/model/upload permissions for the reference itself and result sources. An external reference is not silently imported into the catalog.

### R4

Preview the chosen reference, selected search mode, active hard filters, and score explanation; distinguish a similarity score from probability or character identity.

### R5

Bound reference preprocessing, transient cache retention, result pagination, and cancellation; delete owned temporary reference copies after their documented lifetime.

### R6

Handle offline source, stale ID/version, absent model, tiny/transparent reference, duplicate content, and failed preprocessing without changing search scope.

### R7

Allow switching reference to a returned candidate and returning to previous results while preserving user selections.

### R8

Validate style versus subject confusion and transparency-background effects using creator-art fixtures.

## Failure, boundary, and verification scenarios

- **T1:** Compare same subject/different style and different subject/same style fixtures, palettes, alpha assets, and distractors.
- **T2:** External reference grant expiry, permission denial, no hidden import, no unauthorized upload, and cleanup.
- **T3:** Deterministic filtering/ranking and stale-reference cancellation tests.
- **T4:** Apply the shared contract's relevant authorization, concurrency, cancellation, persistence, recovery, resource, and accessibility checks. Record a reason for any genuinely inapplicable category.
- **T5:** Verify impacted legacy audio behavior and ensure original media hashes are unchanged. Use real media/native/client tests for media/platform claims, not mocks alone.
