# SS-028: Windows application icon resource

Status: in-review
Branch: fix/SS-028-windows-icon-resource
Depends on: 002
PR: pending review

## Goal

SoundShelf must compile on Windows without failing in Tauri's build script.

## Context

Tauri generates a Windows resource file during compilation and expects
`src-tauri/icons/icon.ico` to exist. The repository only contained the PNG
source, causing the Windows GitHub Actions job to stop before Rust tests ran.

## Acceptance criteria

- A valid multi-resolution Windows ICO is generated from the existing
  SoundShelf brand icon and committed at Tauri's expected default path.
- The icon contains more than one embedded image size.
- A platform-independent automated test fails if the ICO is missing, malformed,
  or replaced with a single-image placeholder.
- Frontend and Rust tests continue to pass on the development platform.
- The Windows GitHub Actions job completes `cargo test --workspace --locked`.

## Verification

- `npm test`
- `npm run build`
- `node scripts/cargo.mjs test --workspace --locked`
- Confirm `file src-tauri/icons/icon.ico` reports a Windows icon resource with
  multiple embedded icons.
- Confirm the pull request's `windows-latest` check passes.

## Scope

This ticket supplies the missing build resource only. Installer signing,
platform-specific icon refinements, and release packaging remain in SS-024.
