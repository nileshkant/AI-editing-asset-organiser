## Working design

Qualify downloadable audio classifier and audio/text embeddings via native
inference. Offline recognition uses the SS-016 event-tag/provenance contract;
a cloud provider/key is not required. Identify concrete events such as rain,
thunder, hiss, footsteps and engine, with mixed-event and unknown handling.
Do not ship an unqualified model merely because inference succeeds.

## Acceptance criteria

- [ ] No mandatory model download/key.
- [ ] hash/version/license checked.
- [ ] CPU baseline.
- [ ] explicit disk footprint.
- [ ] models labeled AI despite offline execution.
- [ ] vector indices invalidate by model/version.

- [ ] Enabling a qualified pack adds event-tag jobs on import and supports explicit existing-library enrichment.
- [ ] Offline tags searchable in UI/MCP and portable source catalogs with model/version/coverage provenance.
- [ ] Publish corpus, per-class precision/recall, uncertainty thresholds and rain-versus-hiss confusion before enabling recognition.
- [ ] Pack absent/disabled/uninstalled leaves baseline import, catalog reuse, playback, search and MCP operational.

## Test scenarios

- Offline operation.
- interrupted/corrupt download.
- incompatible CPU.
- known audio evaluation.
- retrieval benchmark.
- memory cap.
- uninstall cleanup.

## Review and completion

Review correctness, failure recovery, file safety and privacy. Record commands and actual outcomes in docs/reviews/SS-017.md. Do not mark complete merely because the UI control exists. Record platform limitations and deferred criteria explicitly. Each fix discovered during review remains scoped to this ticket or gets a follow-up ticket/branch.

## Rollout

No source media mutations. Any persistent-schema change requires a transaction, migration test and compatible rollback or pre-migration backup. Feature flags remain off until their acceptance checks pass.
