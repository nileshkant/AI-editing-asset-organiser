## Required technical behavior

### R1

Add an extraction workspace opened from a current image version, with click/box selection, positive/negative points, candidate masks, overlay opacity, and clear/reset/cancel.

### R2

Map pointer coordinates through zoom/pan/high-DPI and EXIF orientation into SS-040 canonical image coordinates; reject out-of-bounds/nonfinite points and invalid boxes.

### R3

Send bounded prompts to SS-073 backend; debounce interaction and cancel superseded requests. Request generation IDs prevent delayed masks replacing a newer selection.

### R4

Represent each mask as a versioned proposal tied to source hash/model/preprocessing; preserve exact selected source pixels separately from mask data.

### R5

Support multiple alternative masks for ambiguous clicks with explicit user choice; do not assume all foreground subjects should be retained.

### R6

Persist a recoverable extraction draft with source version, prompts, chosen mask identity, and revision. Define draft cleanup/restore and no implicit rendered output.

Store draft/mask bytes in bounded app-owned artifacts with hashes and atomic
DB-reference publication. Include editable artifacts in backup/restore or
report their absence explicitly; a source-sidecar reference alone is not a
recoverable mask. Do not auto-evict unsaved user work as a thumbnail cache.

### R7

Handle offline/missing/replaced source, model failure, empty/full-image mask, low-quality output, and budget/time limits with retry/manual correction guidance.

### R8

Provide keyboard/numeric box controls, accessible selection summaries, focus behavior, undo/redo of selection prompts, and consistent zoom.

### R9

Whole-background removal may be a shortcut only when qualified; selection of a particular object remains the required workflow.

## Failure, boundary, and verification scenarios

- **T1:** Select only one of several objects; refine with positive/negative clicks and verify expected region independently.
- **T2:** All orientation/zoom/DPI transforms and edge/one-pixel boxes; out-of-order responses and rapid clicks.
- **T3:** Restart draft, stale source, empty/full mask, cancellation, unavailable model, and keyboard operation.
- **T4:** Apply the shared contract's relevant authorization, concurrency, cancellation, persistence, recovery, resource, and accessibility checks. Record a reason for any genuinely inapplicable category.
- **T5:** Verify impacted legacy audio behavior and ensure original media hashes are unchanged. Use real media/native/client tests for media/platform claims, not mocks alone.
