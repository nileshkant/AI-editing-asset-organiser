First launch

CreativeShelf is an independent app distributed directly, not through an app store, so your computer asks you to confirm it once.

Mac
  1. Open the downloaded .dmg and drag CreativeShelf into Applications.
  2. Open CreativeShelf. If macOS says it can't verify the app, click Done.
  3. Go to System Settings → Privacy & Security, scroll down and click Open Anyway, then confirm.
Windows
  1. Run the -setup.exe installer.
  2. If "Windows protected your PC" appears, click More info → Run anyway.
Linux

Make the .AppImage executable and run it, or install the .deb with sudo apt install ./CreativeShelf_*_amd64.deb. Verify with gpg --verify FILE.asc FILE using the release key from the release page.
